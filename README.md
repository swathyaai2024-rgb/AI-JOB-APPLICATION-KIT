# CareerCraft AI

CareerCraft AI is an honest job application kit for students and early-career applicants. It helps turn real experience into clear, role-ready application materials while keeping human review in the loop.

## Live demo

[Open the published CareerCraft AI demo](https://careercraft-wf3d5joq.manus.space)

## Included in the demo

- Resume Lab for improving clarity without inventing experience
- Cover Letter Generator for role-specific, editable drafts
- ATS-Style Analyzer for transparent keyword, readability, and section checks
- Truth Checker for unsupported or unverifiable claims
- Portfolio Builder for projects, skills, outcomes, and links
- Self-Intro Script Generator for interviews, networking, and career fairs
- Before-and-After Comparison for reviewing visible edits before sharing

## Responsible AI stance

AI supports the student; it does not replace human review. The interface surfaces verification prompts for claims, avoids presenting heuristic analysis as a real employer ATS score, and keeps production API keys server-side in the intended architecture.

## Run locally

```bash
npm run dev
```

The static demo runs on port `3000`.
